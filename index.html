CodeNest Multi-Dev Guidelines

Every developer in the community can start their own projects and repositories. Simply follow our core standards and rules.

1

Repository Naming Standard

Repo names must be lowercase, hyphen-separated, and descriptive of the stack or purpose.

e.g., web-dashboard-v1, mobile-tracker-app
2

Mandatory README.md

Every repo must contain a structured README.md with project title, features, and setup instructions.

Title, About, Features & Setup Guide
3

Branching & Pull Requests

Direct pushes to `main` are restricted. Create a feature branch and submit a Pull Request.

feature/new-feature -> PR to main
4

Open Source License

All open projects under CodeNest Community must include an open-source license (MIT preferred).

MIT License File required

Steps to Start a Project

  1. Click "New Repository" in the CodeNest GitHub Organization.
  2. Follow the repo naming convention and add a brief description.
  3. Include an MIT License and language-appropriate `.gitignore`.
  4. Fill out the `README.md` and share your project link in Discord!
